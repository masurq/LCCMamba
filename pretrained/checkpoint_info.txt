Due to GitHub file size limitations, pretrained checkpoints are provided through the GitHub Release assets.

The release contains the following pretrained weights:

1. LCCMamba_WHU.pth
   Dataset: WHU-OPT-SAR
   Description: Fine-tuned LCCMamba model checkpoint for WHU-OPT-SAR experiments.

2. LCCMamba_Potsdam.pth
   Dataset: Potsdam
   Description: Fine-tuned LCCMamba model checkpoint for Potsdam experiments.

3. LCCMamba_YESeg.pth
   Dataset: YESeg-OPT-SAR
   Description: Fine-tuned LCCMamba model checkpoint for YESeg-OPT-SAR experiments.

4. vssm1_tiny_0230s_ckpt_epoch_264.pth
   Description: Pretrained VMamba-Tiny backbone checkpoint used for model initialization.

All checkpoints are provided as PyTorch model state dictionaries and can be loaded for inference.
